# Glossary

Terms used to describe Gosli Server, its clients, projects, and executors.

## Terms

**Client**:
An application that connects to Gosli Server to send messages and receive replies or executor output.

**Project root**:
A configured directory under which the server discovers projects.

**Project**:
A directory containing source code in which an executor performs work.

**Executor**:
The CLI program that performs the work requested through Gosli Server, such as `Codex CLI`.

**Request**:
A client instruction asking the server to perform an action or provide information.
_Avoid_: Command, Task
