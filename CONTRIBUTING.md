# Contributing

Work in a separate branch created from the latest `main`. Keep each branch focused on one change and merge it into `main` after review.

Name branches `<type>/<short-description>` using lowercase kebab-case, for example `feat/websocket-ack`.

Types:

- `feat`: new functionality.
- `fix`: bug fixes.
- `docs`: documentation changes.
- `chore`: maintenance, tooling, and other changes without new functionality or bug fixes.
